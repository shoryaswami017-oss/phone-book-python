# 📱 Phone Book in Python

A simple command-line Phone Book application built using Python.

## Features

- Add a contact
- Search for a contact
- Delete a contact
- Display all contacts

## Concepts Used

- Python Dictionaries
- Functions
- Loops
- Conditional Statements
- User Input

## How to Run

```bash
python phone_book.py
```
